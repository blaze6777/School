# Lincoln Elementary School Simulator

A browser-based K–6 school management simulator.

## Features

- Clickable school floor plan
- Three permanent classrooms for every grade K–6
- Census-based teacher staffing requirements
- Student cohorts move up one grade each school year
- New kindergarten census each year
- Sixth graders graduate to middle school
- Teacher age and years of experience
- Teacher salaries
- Evaluations
- Hiring classroom teachers
- Specials teachers for Library, PE, Music, and Art
- Nurse, counselor, psychologist, office, principal, cafeteria, and shared spaces
- Staff reassignment between classrooms
- Budget and payroll tracking
- Annual retirements
- Census projections and staffing alerts

## Run locally

You can simply open `index.html` in a browser.

For best results, use a local web server.

### VS Code

Install the Live Server extension, then right-click `index.html` and choose:

`Open with Live Server`

## Put it on GitHub Pages

1. Create a new GitHub repository.
2. Upload:
   - `index.html`
   - `styles.css`
   - `app.js`
3. Commit the files.
4. Open the repository's **Settings**.
5. Select **Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose your `main` branch and `/ (root)`.
8. Save.

GitHub will publish the game as a website.
