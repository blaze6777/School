# Lincoln Elementary V9.7 — Every Student Matters

Builds on V9.6 with a persistent Student Information System, individual student profiles, academic indicators and growth, intervention/MTSS workflows, behavior referrals and administrative responses, support-service caseload view, family conferences, nurse visits, attendance early-warning/follow-up, school-improvement goals, and long-term student histories.

Open Command Center → Every Student Matters or Principal Hub → Student Information & Support. Existing V9.6 saves migrate through the existing loader and V9.7 writes its own save slot.

The design mirrors common real SIS concepts such as unified student records, attendance, behavior, health, family communication and intervention tracking, but it is a game simulation—not a real SIS, medical record, legal compliance, or special-education compliance system.
