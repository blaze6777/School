# Lincoln Elementary Living School Simulator V5.0

Built from the confirmed-working V3.2 foundation.

Major V5 additions:
- Visible Version 5.0 / build badge
- Teacher names shown directly on classroom map; vacant rooms say VACANT
- Current classroom activity changes with school-day time
- Living school-day clock with +30 minutes, next event, and finish-day controls
- Live nurse, office, late-arrival, early-dismissal, parent-call and discipline activity
- Real threaded Inbox replies with a text composer and preserved sent responses
- Compose new email
- Persistent school history
- Community/PTO snapshot
- Summer readiness dashboard
- V3.2 save upgrade support; V5 saves use a new key and do not overwrite V3.2
